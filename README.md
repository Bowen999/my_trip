# 旅行指南

两份可交互的单文件旅行指南，**直接用浏览器打开 HTML 即可**（电脑、平板、手机均可；无需联网，Google 字体只是可选增强）。

页面里的封面多为手绘插画，点开卡片后会展示真实照片，且照片已内嵌在 HTML 中，单独转发单个文件也能完整显示。

| 文件 | 内容 |
| --- | --- |
| `index.html` | **游客版**（`bowenyang.org/my-trip`）：南行九日 · 吉隆坡 / 新加坡 / 巴厘岛 9 日行程（1/24–2/1，含森美兰三所学校探校、巴厘岛婚礼酒店考察、已订航班与返程，按小时排的日程）。只保留路上要看的内容：出行提醒、三地速览、9 日行程与景点、学校和婚礼场地简介、航班与打包清单。页面里的外文名称都配有中文。 |
| `guide.html` | **导游版**（`bowenyang.org/my-trip/guide`）：在游客版之上多出计划假设与待确认、完整状态提醒、学校预约步骤与英文邮件模板、探校提问清单、婚礼考察清单 / 打分表 / 邮件模板、倒计时、资料来源。 |
| `vancouver-alberta.html` | 海与山之间 · 温哥华 × 阿尔伯塔 7 日游 |
| `new-england.html` | **新英格兰七日**（`bowenyang.org/my-trip/new-england`，导游版，只有一个版本）：波士顿 3 晚 → 缅因州波特兰 1 晚 → 路过普罗维登斯（Brown）→ 罗德岛纽波特 2 晚，2026-11-04 晚 → 11-10，5 人 2 车自驾，最后在纽波特分开。内容：本地文化翻转卡片、本地美食（可按地区筛选）、各城去哪吃、缅因和普罗维登斯的逛和买、7 日行程、15 处景点、开车与停车、倒计时、打包清单、计划假设与待确认、最新状态与提醒。 |

## 本地预览

可以用内置 HTTP 服务快速预览：

```bash
python3 trip_server.py
# 或
python3 -m http.server 8000 --directory .
```

默认会在 `http://localhost:8000/` 打开游客版，`/guide` 跳转到导游版。
