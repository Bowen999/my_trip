# 海与山之间 · 温哥华 × 阿尔伯塔 7 日游

一份可交互的单文件旅行指南。**直接用浏览器打开 `index.html` 即可**(电脑、平板、手机均可;无需联网,Google 字体只是可选增强)。

内容截至 2026-10-09,价格为参考价,出发前请以官网为准。

## 功能

- 四部分:国家与文化 / 7 日行程 / 18 个景点 / 出发前清单
- 全部内容可折叠;每张卡片、每一章都能朗读(浏览器自带语音合成,自动展开并高亮跟读)
- 文字大小可调(85%–170%),深色模式,打印时自动展开全部
- 互动:路线地图小车、翻转卡片、找动物小游戏、遇熊小测验、季节切换、蒸汽钟与吊桥、小费/汇率计算器、可勾选打包清单、实时时差

## 重新生成

页面由脚本生成(Node 18+):

```sh
node src/build.mjs   # 输出 index.html
```

- `src/content.mjs`:所有文字内容
- `src/scenes.mjs` / `src/art.mjs`:程序生成的原创插画
- `src/style.css` / `src/app.js`:样式与交互
